
# AIDMBD International Ltd. - Official Website

Welcome to the official repository of **AIDMBD International Ltd.** website. This project contains the front-end source files for the agency platform showcasing our services, products, case studies, and consultation offerings.

---

## 🚀 Overview

AIDMBD International Ltd. bridges South Asian tech talent with global market needs by delivering AI-driven digital marketing solutions, automation systems, and enterprise software services.

---

## 📁 Repository Structure

The core pages included in this repository are:

* **`index.html`** - Homepage providing an overview of AIDMBD International Ltd.
* **`about.html`** - Company background, vision, and operational model.
* **`services.html`** - Detailed list of marketing and engineering services offered.
* **`products.html`** - Highlights of proprietary tools and internal products.
* **`case-studies.html`** - Real-world portfolio projects and client impact stories.
* **`consultation.html`** - Interactive booking/inquiry section for potential clients.
* **`career.html`** - Current open roles and opportunities to join the team.

---

## 🛠️ Tech Stack

* **Front-end:** HTML5, CSS3, JavaScript
* **Version Control:** Git & GitHub
